## Rule
Follow applicable local instructions. Keep one canonical source for each fact and derive projections from it.

## Rationale
Conflicting guidance and duplicated facts make changes unreliable.

## Application
Read repository guidance and canonical files before editing. Regenerate derived views from their sources.
