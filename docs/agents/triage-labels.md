# Triage Labels

Local tickets record these role strings in their `Status:` line.

| Canonical role | Tracker string | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer evaluation needed |
| needs-info | needs-info | Waiting for more information |
| ready-for-agent | ready-for-agent | Fully specified for an agent |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

Use this mapping whenever a skill applies a triage role.
Repository approval and implementation claim rules still apply.
